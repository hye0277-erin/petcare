# PetCare+ QA Checklist

PetCare+ 작업 완료 전 확인하는 공통 QA 기준입니다.

## 공통 확인

- [ ] 변경 범위가 `TASK.md`의 오늘 작업과 일치한다.
- [ ] 사용자가 만든 unrelated 변경사항을 되돌리지 않았다.
- [ ] 새 파일 또는 수정 파일이 프로젝트 구조와 맞다.
- [ ] 콘솔 오류가 발생하지 않는다.
- [ ] 기존 주요 네비게이션이 끊기지 않는다.

## HTML

- [ ] 태그가 정상적으로 닫혀 있다.
- [ ] 속성 따옴표가 깨지지 않았다.
- [ ] CSS와 JS 경로가 올바르다.
- [ ] 버튼, 링크, 폼 요소의 id/class가 JS와 일치한다.
- [ ] 아이콘 버튼에 필요한 `aria-label`이 있다.

## CSS

- [ ] 선택자가 필요한 화면 범위로 좁게 작성되었다.
- [ ] 기존 공통 UI를 의도치 않게 바꾸지 않는다.
- [ ] 모바일 폭에서 텍스트와 버튼이 겹치지 않는다.
- [ ] 하단 탭바 또는 고정 버튼이 콘텐츠를 가리지 않는다.
- [ ] safe-area padding이 필요한 화면에 반영되어 있다.

## JavaScript

- [ ] 이벤트 리스너가 실제 DOM id/class와 연결된다.
- [ ] 저장, 수정, 삭제, 임시저장이 localStorage에 반영된다.
- [ ] 저장 데이터 출력 시 escape 처리를 한다.
- [ ] 빈 데이터 상태가 깨지지 않는다.
- [ ] 뒤로가기, 상세 이동, 편집 이동 흐름이 정상이다.

## 데이터 흐름

- [ ] 새 기록에 `pet_id` 또는 현재 PetStore 구조에 맞는 식별자가 있다.
- [ ] 날짜 형식이 기존 화면과 호환된다.
- [ ] 기록 추가 후 관련 목록이나 카드가 갱신된다.
- [ ] 삭제 또는 수정 후 화면이 최신 상태로 다시 렌더링된다.
- [ ] draft 또는 임시저장 데이터가 일반 기록과 섞이지 않는다.

## 병원 기록 화면

- [ ] `hospital.html` 목록 카드가 렌더링된다.
- [ ] `hospital-add.html`에서 필수 입력 검증이 동작한다.
- [ ] 저장 후 병원 목록에 반영된다.
- [ ] 상세 화면 이동이 동작한다.
- [ ] 첨부 파일 미리보기, 다운로드, 삭제, 교체 흐름이 깨지지 않는다.
- [ ] 하단 고정 저장 버튼이 폼 내용을 가리지 않는다.

## 실행 QA

- [ ] 정적 파일 직접 열기 또는 로컬 서버에서 주요 화면을 확인했다.
- [ ] 가능하면 Playwright 또는 브라우저 자동화로 주요 화면을 확인했다.
- [ ] 자동화 QA를 생략했다면 이유를 보고했다.
- [ ] QA 결과를 최종 보고에 포함했다.
