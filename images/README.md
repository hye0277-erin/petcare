# 랜딩페이지 이미지 가이드 (landing.html)

랜딩페이지에서 사용하는 이미지와 들어갈 자리를 정리한 문서입니다.
**이미지를 교체할 때는 같은 파일명으로 덮어쓰거나, `landing.html` / `css/landing.css`에서 파일명만 바꾸면 됩니다.**
코드 안에는 `[이미지 교체]` 주석으로 위치를 표시해 두었습니다.

---

---

## 교체 방법 (예시)

### 1) 같은 파일명으로 덮어쓰기 — 가장 쉬움
새 사진을 기존 파일명(예: `dog-walk.jpg`)으로 저장해 이 폴더에 덮어쓰면 끝.

### 2) 다른 파일명으로 교체
`landing.html`에서 해당 `<img src="images/____">`의 파일명만 바꾸면 됩니다.
Hero 배경만 예외로 `css/landing.css`의 `.lp-hero-bg { background: url("../images/____") ... }`에서 바꿉니다.
